# Decision records

Architectural and contract decisions are recorded here as short ADRs. A decision
that changes a contract in `IMPLEMENTATION_PLAN.md` must update, in the same
change, the relevant fixture in Appendix A, the §14 test list, and the §15
acceptance column.

Start from [`0000-template.md`](0000-template.md). Number records sequentially
as `NNNN-short-title.md`, leave accepted records in place, and supersede rather
than rewrite them.
